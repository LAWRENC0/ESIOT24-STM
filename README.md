# Documentation

This folder contains documentation and assets for the Embedded Systems assignment-03 project.

Contents

- `report.pdf` — Project report (PDF).
- `TMS-Breadboard.png` — Breadboard image for the Temperature Monitoring Subsystem.
- `WCS-Breadboard.png` — Breadboard image for the Window Controller Subsystem.

How to use

- Open `report.pdf` to read the full project report.
- Use the PNG images for circuit/breadboard reference when assembling or reviewing hardware.
